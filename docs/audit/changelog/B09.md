## LCP element a fáze (medián běhu)
Vždy hero obrázek (640w WebP, 16–42 KB). Rozpad např. Falcon 9:
TTFB 463 · **Load Delay 1 097** · Load Time 498 · **Render Delay 1 918** ms.

- **Objevení obrázku není problém.** Preload `<link rel=preload as=image
  imagesrcset fetchpriority=high>` je v `<head>`, požadavek startuje 6–8 ms po
  dokumentu (síťový log: 206 ms doc → 206 ms obrázek), `loading=eager`,
  `fetchpriority=high`, rozměry 1280×720.
- **Load Delay ≈ 1 s** = simulovaná soutěž o pásmo slow 4G: spolu s obrázkem
  startují 2 preloadované fonty Plex 400 (17 + 24 KB, priorita High),
  `Base.css` (75 KB raw / 13,7 KB gz, Highest), 3 skripty (9 KB), beacon
  Cloudflare (10 KB), webmanifest. Po CSS přijdou fonty Plex 600 (25 KB) a
  Archivo (91 KB, Very High).
- **Render Delay 0,3–3,4 s** koreluje s pozorovanou FCP téhož běhu
  (465 ms vs 1 542 ms na stejné URL) → **rozptyl je z měřicího stroje**, ne z
  webu. Stejný web, stejná síť, 2× rozdíl jen tím, kolik CPU má Lighthouse.
  RULES.md: jednorázová lokální hodnota nic nedokazuje — tady to sedí i pro
  produkci.
- `render-blocking-resources`: jediný `Base.css`, wastedMs 150–442 ve všech
  15 bězích. Odhad Lighthouse předpokládá inlining celého CSS.
- `font-display: swap` všude, žádný font-display problém.

## Co by pomohlo a proč to není v tomto PR
1. **Kritické CSS / menší stylesheet.** 75 KB CSS blokuje render každé
   stránky. Inlining celého souboru (`build.inlineStylesheets: 'always'`)
   = +13,7 KB gz na každou stránku a ztráta cache mezi stránkami → na
   zpravodajském webu s prefetchem sporné, ne „úzká změna“. Extrakce
   kritického CSS = nová závislost (beasties) + změna pipeline.
2. **Fonty před LCP.** 157 KB ve 4 souborech, 2 preloadované soutěží s hero.
   Zrušit preload / odložit Archivo = FOUT na titulku a logu → design/font
   změna, B09 výslovně chce další souhlas („zachovat glyph/šířkové osy loga“).
3. **Beacon Cloudflare** (10 KB, third-party) — pravidlo běhu 2: Cloudflare
   nesahat.

Žádná z příčin není opravitelná úzkou změnou šablony bez rozhodnutí → jen evidence.
