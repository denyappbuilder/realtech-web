# B18 — IndexNow jen změněné URL (19. 9. 2026, dávka 2)

**Stav:** ZAPARKOVÁNO po technické validaci, bez kódu. Důvod: minimální
implementace nutně mění existující testy (`scripts/test-indexnow-deployment.mjs`),
což pravidlo běhu 3 zakazuje. Validace baseline dopadla dobře — návrh níže je
připravený ke schválení.

## Technická validace (read-only, hotovo)
- **Kde vzít předchozí produkční commit:** poslední úspěšný běh workflow
  `indexnow-after-deploy.yml` na `main` (`GET /actions/workflows/indexnow-after-deploy.yml/runs?branch=main&status=success`).
  Jeho `head_sha` je commit, u kterého skript už jednou ověřil marker
  `/indexnow-deployment.json` na produkci (branch main, exact SHA, digest
  sitemapy) a odeslal ping. Žádný nový stav, žádný secret, stejný token.
  Dnes: 12:54 `6a70c45c`, 12:11 `a2a6ff3b`, 12:03 `385064c9`… (5/5 success).
- **Není to** „rodič commitu“ ani „poslední push“ — je to poslední doložené
  nasazení + ping. Když takový běh neexistuje (první běh po zavedení) nebo
  jeho SHA není v historii aktuálního `main` (`git merge-base --is-ancestor`)
  → **STOP, žádný ping**, chyba do logu (ne celý web).
- **Mapování souborů → URL** (existující routing, nic nového):
  `src/content/clanky/<slug>.md` → `/clanky/<slug>/` + `/` + `/clanky/` +
  `/temata/<category>/` (kategorie ze frontmatteru); `src/data/videos.json`
  → `/videa/`; `src/pages/*.astro` → jen daná statická route. Vše ostatní
  (šablony, komponenty, CSS, skripty, workflows, docs) → **žádná URL**.
- Výběr se pak **protne s ověřenou produkční sitemapou** (už stažená,
  digest ověřen) — nepublikované/smazané zdroje tím vypadnou samy; URL mimo
  sitemapu se nikdy nepošle.
- `git diff --name-only <prev>..<sha>` vyžaduje v checkoutu historii:
  `actions/checkout@v7` má `fetch-depth: 1` → nutné `fetch-depth: 0` nebo
  `git fetch --depth=…` (změna workflow, bezpečná, read-only).

## Proč to teď nejde bez změny testů
`scripts/test-indexnow-deployment.mjs` (fixture řádky ~100–115, 190–195)
očekává u platné identity `result.urls === 2` a 1 POST **celé sitemapy**; fixture
nemá žádnou baseline ani git. S novým chováním by (správně) skončil STOP bez
POSTu → 2 existující asserty padnou. Test je dřívější vědomé rozhodnutí
(B05) → parkuji.

## Návrh minimální implementace (≤ 45 min, po souhlasu)
1. `scripts/indexnow-after-deploy.mjs`: `notifyDeployment` dostane
   `previousSha` (z API výše) + `changedFiles` (git diff) → `vyberUrl(changed,
   sitemapUrls)`; prázdný výběr = `urls: 0`, žádný POST, exit 0 s logem
   „žádná obsahová změna“.
2. `.github/workflows/indexnow-after-deploy.yml`: `fetch-depth: 0`.
3. Testy: rozšířit fixture o `previousRun` + `changed`; nové případy: nový
   článek, změněný článek, jen šablona (0 POST), prázdný výběr, chybějící
   baseline (STOP), baseline mimo historii (STOP). Dva existující asserty
   `urls === 2` → `urls === <počet vybraných>`.
4. Po merge: první ostrý běh = tento merge (jen workflow/skripty) → očekávaný
   výsledek **„žádný ping“**.
