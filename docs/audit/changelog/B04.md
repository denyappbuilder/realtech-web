# B04 — X embedy a komentáře až po kliknutí (19. 9. 2026, dávka 2)

**Stav:** ZAPARKOVÁNO bez kódu. Konflikt s existujícími testy = dřívější
vědomé rozhodnutí (pravidlo běhu 3: testy neměnit, neoslabovat).

## Co zadání chce
Widget X (`platform.twitter.com/widgets.js`) a komentáře (giscus,
`giscus.app/client.js`) načíst až po kliknutí čtenáře; před kliknutím lehký
placeholder s odkazem na původní příspěvek, funkční bez JS, **bez rezervované
výšky** widgetu.

## Co je hotové už dnes (bez změny)
- X: serverová fasáda (`rehype-x-embed.js`) s odkazem „Otevřít na X“ funguje
  bez JS; widgets.js jen u článků s `xPosts` (ne na celém webu).
- Giscus: `<noscript>` únik na GitHub Discussions; sekce jen s env.
